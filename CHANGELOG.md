# Changelog

## 0.1.0 - 2026-11-18

- Initial release.
- Config templates in `configs/` for Zed (`zed-settings.json`), OpenCode (`opencode.json`), Codex CLI (`codex-config.toml`), and Continue (`continue-config.json`).
- Setup & troubleshooting matrix for Cursor, Cline, Roo Code, Zed, Codex CLI, OpenCode, and Continue.
- Dependency-free Node.js endpoint verifier (`scripts/verify-ide-endpoint.mjs`) checking `/v1/models`, `/v1/chat/completions`, and `/v1/responses`.
- Multilingual README (`en`, `id`, `ja`, `zh-CN`) and CI validation workflow.
